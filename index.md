# My Short Agent

My Short Agent is a personal automation tool. Its owner uses it to run their own two YouTube channels. It:

- uploads Shorts that the owner has approved
- reads YouTube Analytics for those channels to decide what to post next

It is not a public service. Only the owner's own Google account is connected.
